# 🍚 몽글이네 도전 반찬

초등 교실 화면에 띄워 함께 쓰는 급식 반찬 도전 기록 앱입니다.
한 입의 용기를 반 전체 점수로 모아 갑니다.

**바로 열기:** https://<계정이름>.github.io/mongle-side-dish/

## 쓰는 방법

1. ⚙️ 설정 → 학생 수·이름·성별, 점수 획득 목표 인원을 입력하고 **설정 저장**
2. 오늘 날짜와 도전 반찬 이름을 적습니다
3. 학생 이름을 눌러 상태를 정합니다 — 누를 때마다 **성공 ✓ → 결석 🤒 → 해제** 순서로 바뀝니다
4. **기록 추가하기** → 목표 인원을 채우면 "1점 추가!" 팝업과 함께 색종이·팡파레가 터집니다

## 점수 규칙

목표 인원은 결석생 수만큼 자동으로 낮아집니다(최소 1명).

| 결석 | 출석 | 목표(기본 3명 기준) |
|---|---|---|
| 0명 | 5명 | 3명 |
| 1명 | 4명 | 2명 |
| 2명 이상 | 3명 이하 | 1명 |

## 저장에 대해

기록은 **그 컴퓨터의 그 브라우저**에만 저장됩니다(localStorage).

- 교실 컴퓨터 한 대에서 계속 쓰시면 그대로 이어집니다
- 다른 컴퓨터나 다른 브라우저에서 열면 기록이 비어 있습니다
- 방문 기록·캐시를 지우면 함께 지워집니다
- 학기가 바뀔 때는 설정 창의 **기록·점수 초기화**를 쓰시면 학생 명렬은 남고 기록만 지워집니다

## 기술 정보

외부 라이브러리·CDN·서버가 전혀 없는 단일 HTML 파일입니다.
인터넷이 끊긴 교실에서도 파일만 열면 동작합니다(글꼴만 기본 글꼴로 대체됨).
